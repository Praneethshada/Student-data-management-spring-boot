Spring Boot Project

A Simple Way to Manage Student Records

EduTrack is a student management system built with Java and Spring Boot. Each institution registers separately and manages its own student data — nothing is shared between institutions.

Get Started See Features

What It Does

Features

A straightforward set of features for managing students at your institution.

🔐

Institution Login

Each institution registers with an email and password. Passwords are stored as BCrypt hashes. Login sets a session cookie that lasts 7 days.

🏛️

Data Isolation

Every student record is linked to the institution that created it. You cannot see or edit another institution's data — enforced at the database query level.

📋

CRUD Operations

Create, read, update, and delete student records. Each student has a name, email, and course. All inputs are validated before saving.

🔍

Search

Search students by name or email. Results are filtered within your institution's data only.

📄

Pagination

Student lists are paginated. You can set the page size and navigate through pages from the UI or the API.

🖥️

Browser UI

A simple HTML interface lets you manage records without using Postman or curl. The UI handles login, session expiry, and error messages.

How It Works

Getting Started

Four steps from zero to managing your student records.

1

Register your institution

Create an account with your institution name, email, and a password. No verification needed — access is immediate.

2

Log in

Sign in with your credentials. The system sets a session cookie that keeps you logged in for 7 days.

3

Add student records

Use the browser UI or call the REST API directly to create, search, update, and delete students.

4

Your data stays yours

All student records you create are only visible to your institution. Other institutions cannot access them.

 REST API Endpoints
POST/auth/register
POST/auth/login
