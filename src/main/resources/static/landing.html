How It Works

Up & Running in Minutes

EduTrack is designed for rapid deployment. No complex configuration, no steep learning curve — just a clean, modern RESTful system that works out of the box.

1

Clone & Configure

Clone the repository and set your MySQL credentials in a simple .env file. No hardcoded secrets, ever.

2

Build with Maven

Run mvn clean install and let Maven handle all dependencies. The build is reproducible and environment-agnostic.

3

Launch the Application

Start the server with mvn spring-boot:run. Your API is live at localhost:8080 in seconds.

4

Manage Students Instantly

Open the web UI or connect your frontend client. Create, search, update, and delete records through clean REST endpoints.

EduTrack REST API — Endpoints
POST/students
→ Create a new student record

GET/students
→ List all students (paginated + search)
?page=0&size=10&query=john

PUT/students/{id}
→ Update student by ID

DELETE/students/{id}
→ Remove student record by ID
